# Chase Mail v0.5

- Added inbox and sent-message search (subject, body and participant username).
- Internal recipient lookup now accepts a Chase Mail username or the matching planned Chase Mail address. This does **not** enable internet email delivery.
- Supabase project connection and existing security policies unchanged.

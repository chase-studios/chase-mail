# Update 10 — Source rewrite candidate

This package is a substantial local-feature update, not a claim that all previously discussed roadmap items are complete. The primary purpose is to provide a coherent PC-editable source baseline and an explicit distinction between implemented, planned and blocked features.

### Implemented in new code
- Four starter eggs per signed-in browser profile
- Hatch with cryptographically random selection and Common/Rare/Epic/Legendary variants
- Twelve species and collection index with undiscovered silhouettes
- Companion levels, experience, happiness, energy, feed/play/rest, selected companion
- Eight theme presets, custom accent and background
- Compact and reduced-motion preferences
- Signature editor (storage only), notification preference (storage only)
- JSON export/import of local personal settings with validation
- Per-user browser storage isolation

### Existing recovered v0.6 functions
Supabase auth, internal mail, drafts, contacts, search, basic appearance and pet widget. These are subject to backend schema availability.

### Not implemented
Actual provider email transport, 2FA, shared portal SSO, verified domain mailbox, server-side collection/trading, push notifications, scheduled delivery, full v0.8 merge, full edition gating.
